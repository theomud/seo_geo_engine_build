# Engine Workflow

## The flywheel

1. Strategy
2. Research
3. Evidence grading
4. Entity mapping
5. Outline
6. Draft
7. Edit
8. QA
9. Publish
10. Measure
11. Learn
12. Improve the system

## Stage gates

### Gate 1: Strategy

Do not create the page unless the opportunity score says build, update, or merge.

### Gate 2: Evidence

Do not publish factual claims without evidence tiers.

### Gate 3: QA

Do not publish if QA returns FAIL.

### Gate 4: Measurement

Do not publish unless the page is added to the live tracker.

## Learning loop

After every page:

- add new reusable facts to evidence_registry.yml
- add new entities to entities.yml
- add FAQ patterns to faqs.yml
- add experiment results to experiments.csv
- update prompts if the same issue repeats
