# Copy & Image Sciences

Verified knowledge base covering the science behind high-converting copy and
trust-building imagery. Built from peer-reviewed research, adversarially
verified claims, and practitioner-consensus principles.

Every claim is marked:
- **FOUNDATIONAL** — seminal work, widely replicated, safe to use
- **ONE SOURCE** — single study; treat as strong hypothesis
- **GAP** — practitioner consensus, no peer-reviewed backing
- **OFFICIAL SOURCE REQUIRED** — regulatory claim needing a live gov link

Claim bank uses Admiralty codes: A1 (5/5 verified) → D1 (killed/quarantined).
