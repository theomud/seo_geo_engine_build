# marketingskills/ — curated "kickass" expert set (17 of 43)

A third-party skill pack, **rated and culled to only the highest-value skills**
that make us experts at a lead-gen *writing* engine. Each is a self-contained
`SKILL.md` (+ `.md`/`.json` references) — text only, no executable code.

## Provenance
- **Source:** https://github.com/coreyhaines31/marketingskills (MIT © 2025 Corey Haines — see `LICENSE`)

- **Curated:** 9 Jun 2026 — all 43 scored by a fan-out quality audit (relevance to a lead-gen writing engine · depth · actionability · accuracy · completeness/"works 100%"). Kept overall ≥8 (plus `image` and `emails`).

## Caveats carried forward
- A few kept skills reference the **excluded `tools/` CLIs** (`emails`, `ad-creative`,
  `image` optimization commands, parts of `seo-audit`). The **written playbook is
  self-contained**; ignore the CLI/integration sections.
- `image` flags deprecated DALL-E and uses `cwebp`/ImageMagick CLI for optimization
  (not installed) — the *prompting* guidance is what's valuable; we render via BFL FLUX.
- These are **practitioner playbooks**, not evidence-graded research. Where they
  conflict with the validated claim bank or the SEO_GEO report, tiered evidence wins.
