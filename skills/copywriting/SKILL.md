# Copywriting & Lead-Gen — compiled reference

**Freedom Dial: HIGH (judgment work).** This is a reference/truth layer, not a procedure.
It gives you principles, evidence tiers, and guardrails — then you reason. There is **no
rigid step sequence** to follow here; the one hard rule is *cite the tier or hedge — never
invent a claim or a number.* (The downstream execution skills — `cro`, `seo-content-writer`,
`emails` — carry their own lower-freedom checklists.)

## How to use this skill
Load it when you need the WHY/evidence behind a writing or persuasion choice. Find the
relevant numbered node (1–26, grouped into 7 levels below), read its **Mechanism/Proven**
line and its **evidence tier**, then act. Treat `[VENDOR]` / `[⚠️CONTESTED]` claims as
attributable, not as law. If you need the full citation or benchmark, open **`EVIDENCE.md`**.

## The one rule (the gold standard)
> **Results beat theory.** A page is good if it *repeatedly produces qualified leads* —
> not if it's clever. Write for the scared human behind the search, tell the truth
> (cite or hedge — never invent), make the next step obvious. Everything below serves that.

# LEVEL 1 — Psychology

### 1. Customer Psychology
**What:** the pain/fear/frustration/desire/objection underneath the search.
**Mechanism:** behaviour fires only when **motivation + ability + prompt converge — Fogg B=MAP** `[T1 corpus]`. If a page fails, *reduce friction or fix the prompt before adding motivation.*
**Frameworks:** Schwartz desire, Maslow, Jobs-to-be-Done; **Kahneman System 1/2** (use the *framing*, not the shaky priming numbers `[⚠️CONTESTED]`).
**Proven:** fear-*acknowledgement* paired with a high-efficacy verified solution is the strongest trust-builder — Tannenbaum 2015 meta-analysis (127 studies, n=27,372) `[T4]`. Acknowledge the fear, don't exploit it (the dark-pattern line `[T1 NN/G]`).
**Execute with:** `customer-research`, `marketing-psychology`. **Mistake:** selling features to System-1 readers who want the fear named first.

### 2. Buyer Journey (Schwartz's 5 stages of awareness)
**What:** Unaware → Problem-aware → Solution-aware → Product-aware → Most-aware. Match the copy's *entry point* to the stage. `[CONSENSUS, framework verified 3-0 deep-research]`
**How:** Most-aware → price/CTA; Unaware → name the problem first. Pet-relo example: "will my dog be taken at the airport" = Problem/Fear-aware → reassurance page, not a quote form.
**Execute with:** `content-strategy`. **Mistake:** writing "book now" copy for unaware traffic.

### 3. Trust Building
**Frameworks:** **Cialdini's 7** — Reciprocity, Commitment/Consistency, Social Proof, Authority, Liking, Scarcity, **Unity** (added 2016) `[T1 corpus + verified 3-0]`.
**Proven:** **E-E-A-T** — Trust is the *most important* component, "Experience" added Dec 2022; it's a **rater concept, NOT a direct ranking factor** `[T2 Google, verified 3-0]`. First-hand experience is the hardest signal to fake (HCU, in core since Mar 2024) `[T2]`.
**Levers:** named expert authors, real reviews/photos, cited official sources, risk reversal/guarantees.
**Execute with:** `copywriting`, `customer-research`. **Mistake:** "our world-class team" (authority you announce ≠ authority you show).

# LEVEL 2 — Website copy

### 4. Headline Writing
**Why:** the highest-leverage element. Ogilvy: "on average 5× as many read the headline as the body" `[CONSENSUS — classic, exact ratio not a study]`.
**How:** specific > vague; lead with the outcome/fear; numbers and concreteness. Hopkins: be specific, sell the result.
**Proven adjacent:** simpler reading level correlates with higher conversion — **5th–7th grade 11.1% vs professional 5.3%** `[VENDOR Unbounce 2024, ⚠️ correlation not causation]`. Write at ~7th grade.
**Execute with:** `copywriting`, `copy-editing`. **Mistake:** clever puns over clarity.

### 5. Value Proposition
**Frameworks:** **MECLABS/Flint McGlaughlin heuristic** `C = 4m + 3v + 2(i−f) − 2a` (Conversion = motivation, value, incentive−friction, anxiety) `[CONSENSUS]`. **April Dunford** positioning (10-step). Answer: what / for whom / why different / why care.
**Execute with:** `copywriting`, `product-marketing`. **Mistake:** "competitive rates, comprehensive solutions" (says nothing).

### 6. Call-To-Action
**Proven:** **one primary CTA per page** — competing CTAs split attention `[Tier-2 corpus]`. Action-specific labels ("Get my quote") beat generic ("Submit").
**Execute with:** `cro`. **Mistake:** five CTAs of equal weight.

### 7. Objection Handling
**How:** list the real objections (too expensive / not sure / not enough trust / need approval) and answer each in-copy; add **risk reversal** (guarantee). Maps to Cialdini commitment + risk reduction.
**Execute with:** `copywriting`, `cro`. **Mistake:** hiding price → the #1 unspoken objection.

### 8. Offer Creation
**What:** people buy *offers*, not services. Frameworks: Hormozi value-equation (dream outcome × likelihood ÷ time × effort); name + package the offer.
**Execute with:** `lead-magnets`. **Mistake:** selling "SEO" instead of "a 90-day lead program."

# LEVEL 3 — Lead-gen writing

### 9. Landing Page Copywriting
**Benchmark:** median landing-page conversion **6.6%**, range **3.8% (SaaS) – 12.3% (entertainment)**, Professional Services **6.1%** — Unbounce 2024 (41k pages) `[VENDOR, ⚠️ paid-skewed; neutral ~2.35% WordStream]`.
**Structure:** hero (fear→promise) → proof → benefits>features → objection/FAQ → single CTA. **Fewer form fields convert better; trust signals near the form** `[Tier-1 Baymard]`.
**Execute with:** `cro`, `copywriting`, `seo-content-writer`. **Mistake:** message mismatch between ad/search and page.

### 10. Lead Magnets
**What:** checklist / guide / calculator / template / report that trades value for an email. Tie it to the money page ("Dubai pet-import checklist" → relocation service).
**Execute with:** `lead-magnets`. **Mistake:** a generic ebook nobody wants.

### 11. Sales Pages (long-form)
**Frameworks:** **PAS** (Problem-Agitate-Solution), **AIDA**, Schwartz, Halbert. Arc: story → problem → agitation → solution → proof → offer → CTA.
**Execute with:** `copywriting`. **Mistake:** agitation without an efficacy-backed resolution (manipulative + less effective — see Tannenbaum).

### 12. Email Copywriting
**Benchmarks (2025):** Mailchimp **35.63% open / 2.62% click / 0.22% unsub**; MailerLite **43.46% open / 2.09% click** `[VENDOR]`. **Apple Mail Privacy Protection inflates opens ~10–15+ pts → optimize on CLICK rate, not opens** `[T2/⚠️]`.
**Sequences:** welcome → nurture → appointment-booking → re-engagement.
**Execute with:** `emails`. **Mistake:** judging success by open rate.

# LEVEL 4 — Blogging, SEO & GEO

### 13. Keyword Research & Intent
**Frameworks:** intent taxonomy — informational / commercial-investigation / transactional / navigational; map each query to the page type that satisfies it `[Tier-2 corpus]`. TOFU/MOFU/BOFU.
**Mechanism:** write for **meaning & entities, not exact keywords** — matching is in embedding space (RankEmbed/BERT); stuffing is also the *worst* GEO method `[T1/T4 SEO_GEO]`.
**Execute with:** `ai-seo`, `content-strategy`, `programmatic-seo`. **Mistake:** one page targeting a head keyword instead of the fan-out sub-questions.

### 14. SEO Content Writing
**Mechanism (T1, sworn DOJ testimony):** ranking ≈ **T\*** topicality (Anchors+Body+**Clicks**) + **Q\*** static *site-wide* authority + **P\*** popularity. **Navboost memorises which result satisfied a query over a 13-month window → win the "long click."** PageRank is now just one input to Q*. `[T1 SEO_GEO]`
**Proven:** Google ranks **people-first content** over search-engine-first `[T2, verified 3-0]`. Q* is site-wide → **topical depth lifts every page** (build clusters, stay focused).
**Execute with:** `seo-content-writer`, `seo-audit`, `ai-seo`. **Mistake:** thin "me-too" pages (HCU drags the whole domain).

### 15. GEO — Generative Engine Optimization
**The core decoupling:** **citation ≠ ranking — 66% of AI-Overview citations come from *outside* the top-20 organic** `[PRIMARY]`. Being cited is a separate game from ranking.
**Proven levers:** add **statistics + quotations + cite your own sources**, in **self-contained passages** → **+25–28%** generative-engine visibility (GEO paper, KDD 2024). ⚠️ **NOT "+40%"** — that's a best-case ceiling on one method on GEO-bench, a proxy metric, domain-dependent; *all three of our sources independently flag this* `[T4, ⚠️CONTESTED]`.
**Corroboration & reach:** AI engines favour triangulated facts — seed presence on **Reddit/YouTube/Wikipedia** (ChatGPT ≈48% Wikipedia in top citations); be visible in **Bing** (ChatGPT ≈87% aligned to Bing). Entity clarity + consistent facts across the web improves retrieval `[T6/Tier-2]`.
**Disowned hacks (no primary support):** `llms.txt`/AI-markdown files, shredding content into tiny chunks, schema-as-a-ranking-factor — Google explicitly disowns the first two `[T2]`.
**Execute with:** `geo-content-optimizer`, `blog-geo`, `ai-seo`. **Mistake:** assuming #1 organic = AI citation.

### 16. Topic Clustering (pillar model)
**What:** a pillar page + interlinked cluster builds topical authority. `[Tier-2 corpus]`
**Evidence note:** HubSpot's 2016 result is **correlational** (impressions rose with internal links); the **causal version was refuted** in our deep-research verify (1-2) `[⚠️CONTESTED]`. The mechanism (Q*/siteFocusScore site-wide) is the stronger basis `[T1/T3]`.
**Execute with:** `site-architecture`, `blog-cluster`, `programmatic-seo`. **Mistake:** an informational post that's a dead end — every post must link to a money page.

# LEVEL 5 — Content strategy

### 17. Customer Research (Voice of Customer)
**What:** interview/mine real customers; copy their *exact words* (forums, reviews, support). Copyhackers VoC. This becomes the headline and the fear line.
**Execute with:** `customer-research`. **Mistake:** writing in your words, not theirs.

### 18. Positioning
**Framework:** **April Dunford, *Obviously Awesome*** — competitive alternatives → unique attributes → value → who-cares-most → market frame. Define who you *don't* serve.
**Execute with:** `product-marketing`. **Mistake:** positioning against "everyone."

### 19. Messaging
**Framework:** **StoryBrand SB7** — Character → Problem → **Guide** → Plan → CTA → Failure → Success (customer is hero; you're the guide) `[verified 3-0]`. ⚠️ "clarity beats product superiority" is a practitioner *assertion*, not a study `[⚠️CONTESTED]` — but clarity is cheap insurance.
**Execute with:** `copywriting`, `product-marketing`. **Mistake:** making the brand the hero.

### 20. Content Mapping
**What:** map content to journey stage — **Awareness = blog/info; Consideration = case studies/comparisons; Decision = service/consultation pages** `[Tier-2 corpus]`. Route/service pages are the **money pages**; blogs capture demand and link in.
**Execute with:** `content-strategy`, `competitors`. **Mistake:** all TOFU traffic, no BOFU money pages.

# LEVEL 6 — Analytics & conversion

### 21. CRO
**Proven:** **~70% cart/funnel abandonment**; fixing the ~32 common checkout/usability issues yields **up to ~35% lift** (a ceiling) `[Tier-1 Baymard]`. Most "best practices" **fail when tested** — context beats dogma `[CONSENSUS CXL]`.
**Execute with:** `cro`. **Mistake:** copying a "best practice" without testing it on your audience.

### 22. A/B Testing
**Statistics (get these right or the rest is noise):** a **p-value = P(data | no effect)**, NOT the probability the effect is real `[T1 ASA, verified 3-0]`. **"Peeking" and stopping when it looks significant inflates false positives to 20–40%+** — fix the sample size in advance or use sequential testing `[T1, verified 3-0]`.
**Execute with:** `cro` (note: the standalone `ab-testing` skill was cut as tool-dependent — the statistics live here). **Mistake:** calling a winner early.

### 23. Lead Attribution
**What:** know which source/content/page created each lead (first-touch, last-touch, multi-touch). **Measure leads & cost-per-lead, not pageviews** — a post with 50k reads and 0 enquiries failed `[Tier-2 corpus, lead-gen objective]`.
**Execute with:** the measurement loop (downstream of this engine). **Mistake:** optimizing traffic vanity metrics.

# LEVEL 7 — Technical

### 24. Website Structure
**What:** home / service (money) pages / landing pages / blog / case studies / contact, in a **hub-and-spoke** with internal links into money pages. `[Tier-2 corpus]`
**Execute with:** `site-architecture`. **Mistake:** orphan pages and dead-end posts.

### 25. UX Fundamentals
**Proven `[Tier-1 NN/G]`:** users read only **~20–28%** of words on a page → front-load (inverted pyramid). The **F-pattern is one of several scan patterns, not a law** — good layout (headings, bullets, front-loading) reshapes it. **Nielsen's 10 heuristics** are the baseline. **Hick's law** (more choices = slower decisions) → reduce options; **Fitts's law** → big, close primary targets. Working memory ≈ **4 chunks** → chunk content.
**Execute with:** `cro`, `copy-editing`. **Mistake:** walls of text; treating the F-pattern as a target.

### 26. Technical SEO
**Proven `[Tier-1 web.dev]`:** **Core Web Vitals "good" = LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1** (INP replaced FID Mar 2024). Meta title/description, internal links, and **schema (JSON-LD: FAQ, LocalBusiness, Service, Breadcrumb)** for eligibility — *not* as a ranking factor `[T2]`. Local SEO (Google Business Profile, consistent NAP, LocalBusiness schema) materially affects location-qualified queries `[Tier-1]`.
**Execute with:** `schema`, `meta-tags-optimizer`, `seo-audit`. **Mistake:** treating schema as a ranking lever (it's eligibility/clarity).

## How to use this with the engine
When writing a page: pick the page's **awareness stage** (skill 2) → write the **fear-led
hero + verified answer** (1, 3, 14) using **VoC words** (17) → add **citable stats/quotes
with sources** for GEO (15) → **one offer + one CTA** (6, 8) → **few-field form** (9) →
gate on **E-E-A-T quality** (`content-quality-auditor`) → ship **schema + meta** (26).
Truth rule throughout: **cite the official source or hedge — never invent** (the
hallucination guardrail, `[T4]`).

## Anti-patterns (what NOT to do)
The per-node **Mistake:** lines above are the specific traps. The cross-cutting ones:
- **Inventing a number.** Never state a stat without its tier; if you can't tier it, hedge.
- **Treating a `[VENDOR]` benchmark as law** (e.g. the "+40%" GEO figure, Unbounce conversion
  medians) — attribute it, note the bias, don't generalize.
- **Selling features to a fear-aware reader** — name the fear first (node 1), then resolve it.
- **Confusing citation with ranking** (node 15) or **schema with a ranking factor** (node 26).
- **Optimizing vanity metrics** — opens over clicks (12), pageviews over leads (23).
- **Pasting playbook steps in here** — execution belongs in the sibling skills, not this layer.
