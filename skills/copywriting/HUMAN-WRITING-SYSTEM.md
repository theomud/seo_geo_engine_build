# The Human Writing System

> How elite writers create original, trustworthy, high-converting content in 2026.
> Objective: **Question → Trust → Lead → Customer** (not traffic).
> Doctrine companion to `KNOWLEDGE-BASE.md`, `15-PRINCIPLES.md`, `BLOG-PLAYBOOK.md`, `AI_Writer_System_Prompt.md`.

## The masters (named authorities — write like them)
- **Eugene Schwartz** — enter the conversation already in the prospect's mind; channel existing desire, don't create it.
- **David Ogilvy** — specificity creates trust ("1,247 leads in six months", not "we help businesses grow").
- **Ann Handley** — write human-to-human; no jargon/buzzwords.
- **Joanna Wiebe** — use *customer language* mined from reviews, sales calls, Reddit, support tickets.
- **Seth Godin** — publish what nobody else can (original data, frameworks, research).
- **Brian Dean** — make the best page on the internet (depth, screenshots, templates, examples, FAQs).
- **Neville Medhora** — write like you talk.
- **Morgan Housel** — stories teach; people forget facts, remember stories.
- **Eddie Shleyner** — curiosity creates attention (headline as open loop).
- **Robert Cialdini** — authority, social proof, reciprocity, consistency, scarcity, commitment.

## The 10 layers
1. **Psychology** — Current State → Desired State → Obstacles → False Beliefs → Emotional Drivers (fear/frustration/hope/desire/pride/status). Buy emotionally, justify logically.
2. **Research** — mine *reality* (Reddit, reviews, sales calls, emails, support tickets), not 3 Google articles.
3. **Expertise** — information is common; *judgment* is valuable ("why relocations fail", not "what is relocation").
4. **Storytelling** — Problem → Mistake → Discovery → Result → Lesson. Attach every lesson to a story.
5. **Authority** — experience · data · research · frameworks · case studies.
6. **Structure** — Problem → Agitate → Solution → Proof → Action (PAS).
7. **Originality** — humans create insight; AI only remixes.
8. **Persuasion** — every sentence must educate / entertain / build trust / reduce risk / create desire / create action — or delete it.
9. **AI-citation** — explicit, structured (lists/steps/definitions/FAQs), sourceable, unique.
10. **Revenue** — every article: what problem · how valuable · what service · what lead magnet · what qualifies the lead · how it earns. Content without revenue alignment is publishing; with it, business.

## The Human Writing Formula (every article)
1. Real customer question · 2. Strong opinion · 3. Original insight · 4. Personal experience ·
5. Supporting evidence · 6. **Story** · 7. Actionable advice · 8. Lead-capture mechanism.

## The ultimate principle
People don't want information — they want **certainty, progress, results, transformation**.
Bad: "Here's information." Great: "Here's how to get the result you want while avoiding the
mistakes that stop most people." *Information teaches; transformation sells.*

## Final rule
Don't write about **topics** — write about **problems**. Don't chase **traffic** — build **trust**.
Don't create **articles** — create **assets**. Don't build **blogs** — build **answer engines**.
