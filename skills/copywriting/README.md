# skills/copywriting/ — the compiled evidence-graded reference

The **truth layer** for the engine's writing half: what's *proven* about copywriting,
lead-gen, SEO and GEO, organized by the 26-skill map across 7 levels.

## Canonical source
- **`KNOWLEDGE-BASE.md`** — the validated, gold-certified "book" (Numini Research Elevator). The
  source of truth; the AI writer RAGs over its backing `claim_bank.csv`. Everything below is the
  working layer derived from / aligned to it.

## The writer (the operational layer — how the engine actually writes)
- **`AI_Writer_System_Prompt.md`** — the **drop-in writer/editor system prompt**. RAG-bound to
  `claim_bank.csv`: asserts only what the bank supports, cites every number, refuses un-banked
  facts, preserves caveats, and (because `blog_objective=lead_generation`) tags the funnel stage,
  links to a money page, uses one primary CTA, and self-checks before output. **This is how we write.**
- **`claim_bank.csv`** (31 validated claims, 17 HIGH/14 MODERATE, Tier-1 ×22) + **`claim_bank_quarantine.csv`** (7 excluded) — the RAG evidence base the writer grounds on.
- **Checklists** the writer + auditor enforce: `SEO_EEAT_Checklist.md`, `GEO_Checklist.md`,
  `Editing_Standards.md`, `AB_Test_Protocol.md`, `Lead_Gen_Playbook.md`.
- **`Validation_Report.md`** — the gold-standard certification (Gate 3 PASS 18/18, 66 tests).

## Files

## The honest status
A reference can carry **Knowledge, Execution, Teaching** — not **Results**. On the
Dreyfus ladder that's **L5 Proficiency**. Mastery/Authority comes only when real
lead-outcome data is fed back (which page/headline/offer actually converted). Theory
is loaded; results are earned in production.

## The one rule
**Results beat theory. Cite the official source or hedge — never invent.**
