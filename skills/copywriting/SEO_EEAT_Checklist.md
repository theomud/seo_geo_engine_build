# SEO & E-E-A-T Checklist (2026)

> Each item is backed by a row in `claim_bank.csv` (pillar `seo_2026`). Confidence shown in
> plain language. **Lead-gen priority:** commercial-investigation and transactional queries
> map to money pages, not blog posts.

## Core principle (read first)

- **E-E-A-T is NOT a direct ranking factor.** It is a quality framework used by human raters;
  "Trust" is the most important component. Treat it as a bar to meet, not a dial to turn.
  *(well-established; Google Search Central -- helpful, people-first content.)*
- The **Helpful Content System was folded into core ranking in March 2024** and is no longer a
  standalone signal. *(well-established; Google March 2024 core update.)*

## Intent & mapping

- [ ] Every target query is classified by intent (informational / commercial-investigation /
      transactional / navigational). *(good supporting evidence; intent taxonomy, Aleyda Solis / Lily Ray.)*
- [ ] Each query is mapped to the page type that satisfies it. Commercial/transactional ->
      route/service **money page**; informational -> blog post that links to the money page.
- [ ] No money-page intent is answered with a blog post (and vice versa).

## Experience, expertise & trust (the spirit of E-E-A-T)

- [ ] Content shows first-hand experience (real cases, photos, specifics), not me-too filler.
- [ ] Clear authorship / accountability and genuine credentials where trust is at stake.
- [ ] Trust signals present: reviews, guarantees, safety/process detail (critical in a
      high-trust niche like moving someone's pet).

## Local / service-area SEO (critical for a service business)

- [ ] Complete, consistent Google Business Profile; NAP consistent across the web.
- [ ] Genuine reviews actively gathered. *(good supporting evidence; Google + practitioner consensus.)*
- [ ] `LocalBusiness` / `Service` / `FAQ` structured data on route and service pages.
      *(well-established; Google structured-data docs.)*

## On-page & technical

- [ ] Page satisfies the query fully and originally; no thin duplication.
- [ ] Internal links from supporting posts up to the pillar and across to the money page.
- [ ] Core Web Vitals "good": LCP <= 2.5s, INP <= 200ms, CLS <= 0.1 (see `web_ux_design`).
- [ ] Crawlable, indexable, fast on mobile.

## Do NOT

- Optimise "for E-E-A-T" as if it were a score.
- Target keywords while ignoring intent-to-page mapping.
- Publish thin content in a trust-heavy niche.
