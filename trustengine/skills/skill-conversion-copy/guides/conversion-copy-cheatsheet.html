name the fear · resolve it · offer help — never invent a number

The 3 moves (in order)

  1. Name the fear — in their words, from a real quote
  2. Resolve it — same breath, cited (C-ID) or honest hedge
  3. Help-first close — give value before the ask
⚑ Done = voice 4+/5 · editorial 40+/50 · CTA passes help-first test.

Move 2 · the one unforgivable error

Never agitate without resolving. "Your dog could be seized!" + no answer = fear-exploiting (P-04 breach = real harm). Always pair the fear with the fix.
No official number? Say so. "No official titer price; owners pay ~700–1,300 AED — get it in writing." (C-001 hedge)
