## MODELS — the data structures and mental models this skill uses

- **M-14 — Documentation Types Model.** The three forms an authority asset takes: **Type 1**
  Documented Case Study (1,500–3,000w), **Type 2** Verified Definitive Guide (3,000–6,000w),
  **Type 3** Field Notes Series (800–1,500w, monthly). This skill's real output is a Type 1.
  *Source:* internal; Hormozi "documentation over creation."
- **M-13 — Proof Density Model.** Proof sits beside every claim, and there is **enough** of it:
  ≥1 verifiable item (C-ID, named figure, dated fact, documented failure) per 200 words. This
  is the gate that makes "authority" countable rather than asserted. *Source:* internal;
  consistent with Fogg et al. (2003) credibility study.
- **M-11 — Content Depth Model.** The asset is comprehensive for its type — a case study is
  complete start to finish, a definitive guide is the most complete resource on its topic — not
  padded to a word count but deep because it documents everything that happened. *Source:* the
  "comprehensive content" pillar (Nielsen 1999).

## FRAMEWORKS — the decision systems and processes

- **F-07 — Documentation Loop.** The engine of the whole skill: complete real work → document it
  with proof → surface the failures/surprises → publish it → it attracts the next client → repeat.
  The work comes first; the asset is its by-product. *Source:* Hormozi — documentation over creation.
- **F-14 — Free Work Content Bootstrap.** Where the cases come from before paying clients exist:
  do real work in public (a free audit, a free walk-through), document every step, publish it as a
  case study — building the proof library first. *Source:* Alex Hormozi.
- **F-29 ★ — Skyscraper Technique.** Why a documented asset earns links: find the best existing
  resource, build something demonstrably more thorough and more proven, then earn the links it
  attracts. *Source:* Brian Dean, Backlinko (2013) — 17 links from 160 outreach emails (11%),
  +110% organic traffic in 14 days.

*Also used:* **F-30** Reverse Outreach (build the documented resource journalists and AI already
search for, so the citations come to you).

## PRINCIPLES — the non-negotiable rules

- **P-13 — Hormozi Test Before Publishing.** *The* bar for this skill: could a basic AI prompt
  reproduce this asset? It passes only when it contains real specifics an AI has no access to — a
  named failure, dated C-IDs, exact figures. Verified by actually running the generic prompt.
  *Source:* Hormozi; paired with Ogilvy's "homework."
- **P-15 — Deliver Then Document.** Real work happens **before** the documentation; documenting
  work that did not happen is fabrication. The documented failure is proof the work was real.
  *Source:* Hormozi.
- **P-31 — Linkable-Asset Standard.** The asset is built to be *linked to* — the standard for a
  genuine linkable asset is real, dense, un-fakeable proof (the benchmark Backlinko sets at ≥50
  referring domains). Density + the Hormozi test are what get it there. *Source:* Brian Dean,
  Backlinko.

*Also used:* **P-03** Proof Over Promise (show, don't tell — every claim carries proof or is cut) ·
**P-11** Real Examples Mandatory (the named real failure/quote over any paraphrase).
