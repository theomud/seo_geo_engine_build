# Skill · File 01 — What This Skill Is
## Niche-agnostic definition of Authority Asset Creation

---

## The problem this skill solves

Type "write a definitive guide to moving a pet to Dubai" into any AI and you get a
competent, complete, useless page — the same page every competitor generated from the
same prompt, trained on the same averages. It ranks nowhere, earns no links, and gets
cited by no AI, because there is nothing in it that could only have come from someone who
did the work. The market is drowning in this content. Adding one more piece changes
nothing.

Authority Asset Creation makes the one thing that prompt **cannot** produce: a resource
**documented from real work** — a real case, a real failure, real evidence — that an AI
cannot fabricate and a competitor cannot copy, because they were not there. It is the
asset that earns the links and the citations precisely because it is un-fakeable.

---

## What this skill produces

| Output | What it is |
|--------|-----------|
| One documented case study | A real case start to finish, proof beside every claim |
| The proof-density record | The count proving ≥1 verifiable proof item per 200 words |
| The Hormozi-test result | What a generic AI prompt cannot reproduce |

The rule that makes it scorable: **≥1 verifiable proof item per 200 words, and a basic AI
prompt cannot replicate it.**

---

## The core idea — document, don't create

*(Library: P-15 Deliver Then Document; F-07 Documentation Loop.)* You do not invent an
authority asset; you **document what actually happened.** The loop: do real work →
document it with proof → publish it → it attracts the next client → repeat. The work comes
first; documenting work that did not happen is fabrication.

Three forms the documented asset takes *(Library: M-14 Documentation Types)*:

| Type | Length | What it documents |
|------|--------|-------------------|
| 1 · Documented Case Study | 1,500–3,000w | one real case, start to finish |
| 2 · Verified Definitive Guide | 3,000–6,000w | the most complete, most-cited resource on a topic |
| 3 · Field Notes Series | 800–1,500w monthly | real work as it happens — the compounding asset |

Before paying clients exist, the **free-public-work bootstrap** generates the library: do
real work in public, document every step, publish it as proof. *(Library: F-14 Free Work
Content Bootstrap.)*

---

## The Hormozi test — the un-fakeable bar

*(Library: P-13 Hormozi Test Before Publishing.)* The asset must pass one question: **could
an AI produce this from a basic prompt?** If yes, it is not an authority asset — it is the
mush. It passes only when it contains what an AI has no access to: a **named real failure**,
**dated source citations** (C-IDs), **exact figures**, the **counter-intuitive thing that
actually happened**. Proof density makes this measurable *(Library: M-13 Proof Density)* —
≥1 verifiable item per 200 words means the page is mostly evidence, not prose an AI could
generate.

---

## A worked example (the proof niche)

The **airport-confiscation case study**: a real customer who nearly had their dog held at
Dubai airport, documented start to finish. What makes it un-fakeable:

| Element | Why an AI can't produce it |
|---------|---------------------------|
| The named fear in real words | Muze Gu's *"taken away… never give back"* — a real quote, not invented |
| The exact document that saved it | the rabies titer, cited to MOCCAE (C-019) — a dated source |
| The release fee | 500 AED/dog (C-003) — a real, checkable figure |
| **The failure** | what went wrong on the day — the surprise only the person there knows |
| The outcome | what actually happened, not a hypothetical |

A generic AI prompt produces "ensure all documentation is in order to avoid issues at the
airport." The documented case produces the dated MOCCAE rule, the real fee, and the thing
that nearly went wrong — which is exactly why it earns the link the generic page never will.

## How it differs from neighbouring skills

| Skill | Owns |
|-------|------|
| Conversion Copy | the **short page words** — headline, opening, CTA — that convert |
| Editorial Judgment | **whether** a draft is good enough — the /50 gate |
| **Authority Asset Creation** | the **long-form documented resource** built from real work that earns links + citations |

Conversion Copy writes the page that converts a visitor; Authority Assets writes the
3,000-word documented case that *brings* the visitor (and the links and the AI citations)
in the first place. One converts; the other earns authority.

---

## Why this is a standalone skill

1. **It is the only content AI can't commoditise.** Real documented work is the moat when
   everyone else is generating from the same prompts.
2. **It compounds.** Each documented case attracts the next client, who becomes the next
   case — the documentation loop runs itself.
3. **It is portable and checkable.** Every market has real work to document; proof density
   and the Hormozi test make "authority" objective, not a claim.

---

## In scope / out of scope

**In scope.** Documenting one real case (or guide, or field note) start to finish with proof
beside every claim; counting proof density; running the Hormozi test; the free-public-work
bootstrap method.

**Out of scope.** Verifying the underlying facts (done upstream — this skill *cites* the
verified claim, it doesn't decide it's true), the short conversion copy of a landing page,
and the page architecture. This skill documents real work; it does not originate the facts
or the site.

---

## What "good" looks like

- **Proof density ≥1 verifiable item per 200 words** — C-ID citation, named figure, dated
  fact, or documented failure — counted and shown.
- **The Hormozi test passes** — a basic AI prompt cannot reproduce the asset; an independent
  reviewer confirms what it can't produce.
- **At least one real failure or surprise** is documented — the un-fakeable core.
- **Every claim carries proof** (a C-ID or a real, checkable specific) or is cut.

This skill is complete when one documented case study exists for the proof niche meeting the
proof-density and Hormozi-test gates, the proof-density count is shown, and the audit passes.
