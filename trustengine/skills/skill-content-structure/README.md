# CONTENT STRUCTURE FOR TRUST
## Page architecture that converts fear into action in regulated service markets

---

## What This Skill Is

Most content frameworks are built around topics.
This skill builds around the fear behind the topic.

In regulated service markets — immigration, medical, legal, financial,
animal welfare — customers do not arrive at a page curious. They arrive
afraid. Afraid of getting it wrong. Afraid of the consequence. Afraid
that nobody will tell them the truth.

Content Structure for Trust is the architectural framework that meets
that fear head-on. Every page built with this skill follows the same
proven structure: acknowledge the fear first, provide the verified
answer second, show the evidence third, offer the next step last.

This is not a writing style. It is a structural system. It determines
what appears in the first 100 words, what the subheadings say, where
the official sources appear, where the social proof sits, and what the
call to action asks for. The structure is the same on every page.
The content inside it changes.

## The Core Structure — Every Page

```
LAYER 1 — FEAR ACKNOWLEDGEMENT (first 100 words)
The exact fear the customer arrived with.
Written in their language. Not the company's language.
Source: Column K from the fear-mapped keyword research output.

LAYER 2 — VERIFIED ANSWER
The direct answer to the fear.
Cited against an official source from the Source Bank.
Format: plain English translation + exact quote + source URL + date verified.

LAYER 3 — PROCESS OR EVIDENCE
The step-by-step or the proof.
Screenshots of official documents, real photos, named sources.
Not stock images. Not generic assurances.

LAYER 4 — RELATED FEARS
Two or three related fears this customer likely also has.
Internal links to the pages that address them.
Keeps the customer moving through the site toward a decision.

LAYER 5 — THE HELP-FIRST CTA
Not "Get a Quote." Not "Contact Us."
"Download the checklist." "See the step-by-step timeline."
"Talk to someone who has done this route before."
The CTA earns the click by offering something useful.
```

## The 9 Page Types

Every page in a regulated service market fits one of these types.
Each type has its own structural variation.

| Page Type | Intent | Fear Addressed | CTA |
|-----------|--------|---------------|-----|
| Fear Resolution Page | Fear | Specific worst-case fear | Reassurance resource |
| Process Guide | Informational | Overwhelm — don't know where to start | Step-by-step download |
| Route/Variant Page | Commercial | Route-specific documentation mistake | Route checklist |
| Cost Transparency Page | Commercial | Price gouging — no way to know if fair | Cost estimator |
| Comparison Page | Research | Choosing wrong provider | Trust Score comparison |
| Urgency Page | Urgency | Timeline — a deadline is approaching | Decisive timeline CTA |
| Emergency Page | Emergency | Acute crisis happening now (pet stuck, flight imminent) | Immediate contact above the fold |
| Case Study Page | Problem | "Will this actually work for someone like me?" | See how we solved this |
| Trust Page | Research | "Can I trust this provider at all?" | Credentials / guarantee |

The three additions extend the framework to the full search-intent surface. **Emergency** is split from Urgency (crisis-now vs deadline-approaching); **Case Study** documents one real completed relocation as proof; **Trust** concentrates credentials, licences, named team and guarantees. How these page types connect into a journey — conversion-path design, sitemap/URL structure, navigation, and the service/location hierarchies — is owned by **a separate site-architecture skill**; this skill structures the page, that skill structures the site.

## The Models, Frameworks and Principles

### MODELS

**The Fear-First Content Model**
Every page has one primary fear. That fear appears in the first sentence.
Everything else on the page resolves that fear or prevents related fears.

**The Verified Fact Model**
Every factual claim has three components:
- Plain English statement
- Exact quote from official source
- URL + date verified

No claim appears on a page without all three components in the Source Bank.

**The Trust Layer Model**
Trust is built in sequence — not all at once.
Layer 1 (fear acknowledgement) builds emotional trust.
Layer 2 (verified answer) builds informational trust.
Layer 3 (evidence) builds credibility trust.
Layer 4 (related fears) builds completeness trust.
Layer 5 (help-first CTA) builds relational trust.

### FRAMEWORKS

**The Intent × Fear Matrix**
Every keyword has an intent type (from the fear-mapped keyword research Column J —
now **8 intent types**: Informational, Problem, Fear, Urgency, Emergency,
Commercial, Transactional, Research) and a fear statement (Column K). The
combination determines the page type.

| Intent | Fear Category | Page Type |
|--------|--------------|-----------|
| Fear | Confiscation | Fear Resolution Page |
| Informational | Overwhelm | Process Guide |
| Commercial | Price gouging | Cost Transparency Page |
| Commercial | Route documentation mistake | Route/Variant Page |
| Urgency | Deadline approaching | Urgency Page |
| Emergency | Crisis happening now | Emergency Page |
| Problem | "Will this work for someone like me?" | Case Study Page |
| Research | Wrong provider | Comparison Page |
| Research | "Can I trust this provider at all?" | Trust Page |

**The 4-Second Sorting Funnel**
Intent + Fear = Page Type in 4 seconds.
No deliberation. No committee. The matrix decides.

**The Opening Formula**
[Fear statement in customer language] + [Reassurance bridge] + [What this page gives them]

Example:
"If you have been told your dog could be confiscated at Dubai airport —
that fear is real and it has happened. This page explains exactly what
triggers it and the three steps that prevent it."

### PRINCIPLES

**Fear-acknowledging not fear-exploiting**
Acknowledge the fear to resolve it. Never amplify it to sell.
The test: does this opening make the customer feel understood or more anxious?

**Verified before published**
No factual claim appears on any page without a Source Bank entry.
Source Bank status must be Verified — not Unverifiable, not Pending.

**Structure is not style**
The 5-layer structure is mandatory. The writing style within it adapts
to the niche, the persona, and the route. The structure does not change.

**One fear per page**
Every page addresses one primary fear completely.
Related fears get their own pages with internal links.
A page that tries to resolve five fears resolves none of them.

**Screenshots as standard**
Every page includes at least one screenshot of an official source document.
This is not decorative. It is proof. The screenshot is what makes the
verified claim visible to the reader.

## How To Do This Manually

Full instructions: files/02-how-to-do-it-manually.md

Time per page: 45-90 minutes
Tools needed: Source Bank spreadsheet, keyword spreadsheet, browser

Quick steps:
1. Identify the primary fear from Column K of the keyword spreadsheet
2. Find the verified answer in the Source Bank
3. Write the fear acknowledgement opening (first 100 words)
4. Write the verified answer section with official source citation
5. Add process steps or evidence (screenshots of official documents)
6. Add 2-3 internal links to related fear pages
7. Write the help-first CTA

## Functional Quality Threshold

The functional output of this skill is the set of page briefs/drafts in `data/content-structure-templates/`. A brief passes only if it clears all five structural gates: (1) Layer 1 names the page's one primary fear in verbatim customer language; (2) every factual claim in Layer 2 cites a **Verified** Source Bank row by C-ID, and any number without an official source is explicitly hedged — never asserted; (3) Layer 3 carries at least one real official-source screenshot (or a named path to one for comprehensive drafts); (4) Layer 4 links to ≥2 related-fear pages; (5) Layer 5 is a help-first CTA, never "Get a Quote." **Threshold: 100% of briefs clear all five gates with a 100% verified-citation rate on asserted facts.** Measured on the Dubai proof run (2026-05-29): **4 of 4 universal-gap pages clear all five gates; verified-citation rate = 100%; every unverified figure (titer 700–1,300 AED, summer-embargo dates, the "Sharjah hack") is hedged, and the one real source conflict (Etihad USD 399 vs community USD 1,500, C-015) is surfaced.** Threshold MET.
