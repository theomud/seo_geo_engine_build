## 3. Verification checklist (File 03 gates — all must pass)

- ☐ G1 Opens with the fear in customer language (not company/keyword)
- ☐ G2 Every fact cites a Verified row; no Unverifiable claim asserted as fact
- ☐ G3 Real evidence present (official screenshot / named proof)
- ☐ G4 2–3 related-fear links (real or logged as required pages)
- ☐ G5 CTA is help-first
- ☐ G6 Exactly one primary fear
- ☐ G7 Acknowledges fear, does not exploit it
- ☐ Page type correct for intent; correct layer carries the page
- ☐ Word count within the chosen depth band
- ☐ (Emergency) short, contact CTA above the fold · (Case Study) real verifiable specifics · (Trust) every credential checkable
