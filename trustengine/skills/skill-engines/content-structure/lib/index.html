Why it matters

This is one engine in the Trust Engine. A page can look fine and still fail the one signal that actually wins ranking, AI-citation or a customer's trust. This engine turns that invisible signal into a number you can see, fix and re-check — so an improvement is provable, not a guess.

How it works

  1. Reads the live page — fetches the URL (read-only GET, respects robots.txt) and renders its JavaScript, so it scores exactly what a visitor and a search engine actually see.
  2. Runs every measurement — each signal is scored from the real page content, never invented.
  3. Scores & grades — points add up to a 0–100 score and an A–F grade, with what that grade means.
  4. Says exactly what to fix — ranks the highest-impact fixes first, each with the action to take.

Honest by design: anything that can't be seen on the page (off-page signals) is shown as Not Measurable rather than faked. Every check in the results opens to show its own how it works and why it works.
