The blueprint, before page 11

Design the whole site first: sitemap · URL rule · navigation · conversion paths. Build page-by-page and structure happens by accident — cannibalisation, buried pages, orphans.

The 3 gates (every page, no exceptions)

  1. ≤3 clicks from home (BFS depth) — F-33
  2. 0 orphans — every page has ≥1 inbound link — P-37
  3. 100% URL consistent — one rule per type — P-36
+ human gate: one page per intent (P-23) — merge two pages chasing one query. No "95% consistent" — one exception breaks the rule.

Click depth is counter-intuitive

A page that "feels" 2 clicks can be 4 — if it's linked only from a sibling, not its hub. Eyeballing misses it; only the BFS count catches it. Link every page from its hub.
