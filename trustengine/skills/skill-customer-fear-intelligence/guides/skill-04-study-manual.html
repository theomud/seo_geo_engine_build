The 4-Second Sorting Funnel

Given any keyword, instantly know the page type, the opening sentence, and the CTA.

Why the funnel exists

Files 02 and 03 fill Column J (intent) and Column K (fear). File 04 uses those two columns together to produce a third output: the complete page brief in one line. It is the bridge between keyword research and content creation, and it feeds straight into Skill 03 (Content Structure for Trust).

Second 1Read the intent type (Column J).
Second 2Read the fear category (Column K).
Second 3Match to the funnel table.
Second 4Write the one-line page brief.

Intent + Fear = Page Brief

Intent + Fear → Page type + Opening sentence + Primary CTA

The intent decides the page shape; the fear decides the page opening. Together they're a brief precise enough to hand to a writer.

Worked example

Keyword: "will my dog need quarantine in Dubai"

Intent: Fear  ·  Fear: rejection / quarantine separation

Page type: Reassurance page

Priority scoring — what to build first

Priority Score = Source Count × Intent Weight
IntentWeight
Urgency× 3
Fear× 2.5
Commercial× 2
Informational× 1.5
Transactional× 1

Source Count is how many collection sources surfaced the keyword (autocomplete, alphabet, PAA, related, community). Higher score = build first. The briefs and scores go into a new "Page Briefs" sheet: Keyword · Intent · Fear · Page Type · Opening · CTA · Priority Score.

Building the content calendar

Sort the Page Briefs sheet by Priority Score, descending. The top of that list is your first three months of content. Cross-reference with Column H (seasonal peak): build Oct–Apr commercial/route pages before the September surge; use the Jun–Sep embargo window for evergreen educational pages that rank in time to convert in October.
