# Quality Standard

Every page must pass these standards before publishing.

## Content quality

- Clear purpose
- Clear audience
- Clear search intent
- Helpful answer
- No filler
- No keyword stuffing
- No vague claims
- No unsupported claims

## SEO quality

- Target keyword mapped
- Search intent matched
- H1 clear
- Title tag clear
- Meta description clear
- Internal links included
- Relevant entities included
- Page answers the query fully

## GEO quality

- Self-contained passages
- Clear definitions
- Citable facts
- Statistics where appropriate
- Sources cited where appropriate
- Questions and answers included
- Content structured for extraction

## Conversion quality

- Clear CTA
- Trust signals
- Objections answered
- Next step obvious

## Measurement quality

- Page added to tracker
- Target keyword recorded
- Conversion event recorded
- Review date set
