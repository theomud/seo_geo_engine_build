# Department Principles

These principles are the highest authority in the system. If any prompt, workflow, agent, or tool conflicts with these rules, these rules win.

## 1. Get the right people first

Before strategy, ensure the correct people, tools, prompts, workflows, and systems are in place.

Anything that repeatedly creates confusion, waste, or poor quality should be removed.

## 2. Remove what does not help

A strong system is built by removing what is weak, messy, slow, duplicated, or confusing.

Remove bad systems, unclear processes, tools nobody uses, weak prompts, and tasks that create problems again and again.

## 3. Face the truth

Never guess. Never hope. Never lie to yourself.

Use data, evidence, testing, and measurement.

Truth outranks opinion.

## 4. Find the strongest focus

Do not try to do everything.

Prioritize work that sits at the intersection of:

1. What we can become excellent at
2. What can create money
3. What we can sustain for a long time

## 5. Build discipline

Follow processes. Document decisions. Do not chase every new trend.

Consistency beats intensity.

## 6. Use technology as an accelerator

Technology serves strategy. Technology is not the business.

Only use technology when it strengthens the core engine.

## 7. Build a flywheel

Research → Create → Publish → Measure → Learn → Improve

Repeat indefinitely.

## 8. Protect the core engine

The core engine is:

Research → Knowledge → Content → Trust → Leads → Revenue

Do not let random ideas, bad tools, weak processes, or hype damage the engine.

## 9. Make the system stronger every time

Every task should improve prompts, SOPs, workflows, knowledge, tracking, and quality.

The goal is not just to finish tasks. The goal is to make the whole system stronger.

## 10. Remove or repeat

Ask:

- What works?
- What creates trust?
- What creates money?
- What should be repeated?
- What should be removed?

Build the system around the answers.

## Final rule

If a decision conflicts with these principles, the principles win.
